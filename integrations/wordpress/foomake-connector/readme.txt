Connects WooCommerce stores to FooMake import workflows.

== Description ==

FooMake Connector prepares a WooCommerce store for FooMake customer, product, and sales order import workflows.

This early connector package is distributed directly from FooMake and is not submitted to the WordPress plugin directory.

== Installation ==

1. In WordPress admin, open Plugins > Add New > Upload Plugin.
2. Upload the zip downloaded from FooMake.
3. Activate FooMake Connector.
4. Open WooCommerce > FooMake, enter your FooMake URL, and click Connect to FooMake.
5. Approve the pairing in FooMake.
6. In FooMake, open Profile > Connectors to verify plugin status and save WooCommerce credentials when needed.
